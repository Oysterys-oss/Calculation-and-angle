📌 Excel 匯入格式

目標點號： A10、A11、A12……
實測邊長： E9、E10、E11……
實測夾角： L8/M8/N8、L9/M9/N9……

配對： A10 + E9 + L8/M8/N8
A11 + E10 + L9/M9/N9
A12 + E11 + L10/M10/N10

📂 已知點座標資料庫

已知點資料庫獨立保存。
不會因為新增、刪除或匯入導線資料而被修改。
可以一次從 Excel / 文字資料複製多筆資料貼上。
大量貼上格式：
每一行一個點： 點號　N座標　E座標

例如：
A01 2500000.1234 300000.5678
A02 2500010.5678 300010.1234
也支援從 Excel 直接複製三欄後貼上。

📊 導線前瞻點序列

Excel： A10:A11:A12... ＝目標點號
Excel： E9:E10:E11... ＝實測邊長
Excel： L/M/N ＝實測夾角 度/分/秒

⚠️ 本區已移除「大量貼上導線資料」功能。
📐 方位角計算： 本系統使用測量導線常用方式：
後視方向 → 反向後視方向（+180°） → 加入實測夾角 → 得到下一邊方位角。

因此不會再出現原本 「方位角差 180°」的問題。
